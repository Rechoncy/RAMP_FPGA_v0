# 执行序列示例

在“方案设计与保存 → 执行序列”点击“导入”，选择这里的 JSON，再保存。
这些文件只包含本地方案；导入、选择和保存不会改变 DAC 输出。

| 文件 | 行为 |
|---|---|
| 固定时间表.json | 一次输入 1 上升沿后：A 从 0 µs 开始，B 从 200 µs 开始，C 从 400 µs 开始，500 µs 结束 |
| 无限重复时间表.json | 同一时间表每 500 µs 连续循环；只需一次输入 1 上升沿，点击中止停止；需要新版无限重复固件 |
| 不同输入事件序列.json | 输入 1 上升沿播放 A → 输入 2 门控 B → 输入 1 下降沿播放 C → 重新等待 A |
| 共用输入事件序列.json | 上述三个步骤全部使用输入 1；每个边沿只用于当前已准备好的步骤 |

均为 10 位、统一初始/中止码 512，目标原码为 256 / 128 / 400。固定表为 1505 码段，事件表为 1508 码段，适合每路 2048 码段的四路配置。它们是便于操作的示例，不是用户现有实验方案，也不是数字验证镜像内置的短脉冲快照。

完整解释见“文档/执行序列使用说明.html”。普通 UART 下载只写 RAM；需要掉电保留时，应把所选序列纳入上电方案后重新构建与固化。
