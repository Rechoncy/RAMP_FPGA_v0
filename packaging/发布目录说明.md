# Ramp Studio 发布目录

双击 **Ramp Studio.exe** 启动；程序图标和运行库已内置。

R2 USB FIFO 已在当前 125 MSPS 固件完成补测：选择 **USB FIFO · FTAE79DQ** 连接，无需波特率，每路 2048 段约 90 ms；四路播放与重连正常。见 `文档/USB_FIFO_R2实板验证_2026-09-17.html`。本次补测未改动 EXE、BIT 或 Flash。

新版 R2 固件支持连接时自动识别 9600～1M 波特率，已在当前 CH340 串口实板验证。同一份固件切换速率只需“断开 → 选择波特率 → 重连”；旧固定速率固件先升级一次。USB FIFO 不使用波特率。固件单独位于 `FPGA-XC7A35T-AutoBaud-20260917-R2/125MSPS/` 及同名 ZIP，详见 `文档/UART实板验证_2026-09-17.html`。本轮临时 JTAG 加载 `09171830`、125 MSPS，未写 Flash；掉电会恢复原 Flash 版本。此后的软件启动不会自动烧写。

分段线性插值用于减少高位宽平滑波形的存储段数，仍为每路 2048 个槽位。设计页可显式选择编码与原码误差；`插值示例/14bit_gaussian_gate.json` 可导入查看 14 位、70 μs 进入 / 返回高斯。先阅读 `文档/14位高斯分段插值.html`，完整检查再下发。旧参考 BIT `09133301` 不支持插值；新诊断 BIT `09171701` 已支持插值，但实际接口为四路 10 位，使用 14 位接口仍需核对接线并重新构建。更新程序不会自动烧写 FPGA 或 Flash。

正常退出自动保存设置和草稿，下次启动恢复板卡 / Flash 输入、波形 / 序列 / 扫描草稿、时间单位、DAC 分配、Debug 待提交原码及上次页面。会话位于 `user_data/desktop_session.json`，迁移时随整个 `user_data` 复制。自动保存草稿不替代“保存方案”，也不会自动下载；启动保持未连接，不自动布防或输出。保存失败会提示原因并保留窗口。

**最省心的迁移方法：把本机 `E:\Github_Project\RAMP_FPGA_v0\release` 整个文件夹复制到新电脑。** 例如粘贴为 `D:\RampStudio\release`，然后双击其中的 `Ramp Studio.exe`。这样会同时带走现有 user_data。具体文件夹名称与摆放示意见本目录的 [迁移说明.html](迁移说明.html)。

需要较小的传输包时，复制 `Ramp-Studio-Windows-x64.zip`，再另外复制整个 `user_data`；便携 ZIP 本身不含本机实验数据。

“板卡与连接”已拆分为“板卡信息”和“引脚配置”独立页面；默认及逐路时序统一放在“DAC 时序”，保存与导入导出操作固定在底部。

参考时钟支持单端或差分输入，提供 50 / 100 / 200 MHz 选项，核心及 DAC 输出可选 100 / 125 / 200 MSPS（3PD5651E 最高 125 MSPS）。输入形式、频率、时钟 IO 标准与差分终端在“板卡信息”设置，单端或 P/N 接线在“引脚配置”填写。当前构建适配器支持 Xilinx 7 系列，换用另一种参考输入需重新生成并烧写固件；本机原单端 50 MHz 配置保持兼容。

本版进一步整理全部页面：窄窗口折叠方案库、表单自动排列，序列按执行模式只显示相关参数，静态输出统一进入 Debug，单路及多路运行控制固定可见。未保存序列在切换方案前提供保存/取消选项。

时间单位切换保留填写数字，例如 `70 ms → 70 µs`。实际时长按新单位计算，保存并重新下载方案后生效；详见“文档/时间单位.md”。

触发步进数字验证固件标识为 `09133301`，保留序列、整表无限重复等能力，并增加逐触发扫描。镜像没有内置实验上电方案，配置后各 DAC 等待码为 512；使用时先准备自己的方案。上一版 `091217B1` 已归档到开发仓库的 `archive/历史固件/FPGA-XC7A35T-Sequencer-091217B1.zip`，保留原始内容供回退。烧写前阅读对应固件文件夹内的“使用与验证说明.md”；核心 200 MHz 时序通过，DAC 板级接口时序仍待实测确认。

历史固件和上一个软件版本已移入开发仓库的 `archive/`。本地实验数据不会随发布包打包，不要用空白 user_data 覆盖已有数据。

本版提供可选 FT232H 同步 USB FIFO，启用后同一份固件仍保留 UART，软件选择其中一种连接。波形仍存于片内 BRAM，四路每路每 bank 为 2048 段；逐码保持最短 5 ns，线性插值最短 160 ns。USB 不增加波形容量，也不改变 DAC 的 200 MHz 输出。9 月 17 日新诊断固件 `09171701` 已临时 JTAG 下载并完成 USB 数字联调，Flash 未改写；详见 `文档/USB实板数字验证_2026-09-17.html`。该固件包单独位于 `FPGA-XC7A35T-USB-UART-20260917.zip`，不包含在软件便携 ZIP 内。诊断时序模板为 `板卡示例/xc7a35t_usb_uart_diagnostic.json`，其中 −0.5 / +1.0 ns 为假设值，换 DAC 或板卡仍须核对。

“输出控制”提供总览与单路大图，支持已加载/本地方案对比、“准备”按需下载并布防、每路触发设置和独立 Flash 纳入选择。原启动快捷方式继续可用。使用新增触发步进需要升级一次 FPGA 固件；普通波形功能仍可连接原固件，EXE 更新不会自动烧写 FPGA。

“波形库”编辑器仅保留单幅度 Ramp 和自定义函数，旧 FM 扫描输入已移除。历史分段方案只读查看，三段结构可转换为新的 Ramp 副本；“恢复历史草稿”可读取保留的旧草稿。原方案不会自动转换或下载。

新增独立“触发步进”子页：起始码、正/负步长、点数、末点保持或循环；保存后在 DAC 页准备。触发扫描由 FPGA 执行，使用该功能需升级一次对应固件。教程位于“文档/触发步进使用说明.html”。
