# 初始值、触发接线与 DAC 扩展

本版提供可设置的初始码、独立选择的触发输入及边沿，以及 1～8 路 DAC / 1～8 个触发输入。支持 10/12/14 位 DAC 原码，同一工程统一位数；详见 [DAC 位数设置](DAC位数设置.md)。下面的中点及总线映射例子以 10 位为例。重启 Ramp Studio 即可看到新控件。

## 设置初始值

在“波形工作台”设置“初始 / 结束码”。例如初始 300、目标 700，Ramp 就是 **300 → 700 → 300**，仍然只需要一个目标幅度。三个时长分别控制渐变、保持和返回。

“中止码”单独设置，例如 444。下载提交成功后所选 DAC 输出初始码；点击布防后等待触发，正常完成回到初始码，点击中止回到中止码。重新布防或取消布防时恢复初始码。独立多路固件中，其他 DAC 保持各自配置；普通镜像上电/失锁复位输出数字中点。新版可将上电方案纳入比特流并固化，完整启动恢复快照，详见 [Flash 固化与启动](Flash固化与启动.md)。

函数中可用大写 `I` 引用初始值。例如初始 300，函数 `I + 200*sin(2*pi*t/T)` 的范围为 100～500。函数仍按 200 MHz、每 5 ns 计算和取整；最后一轮完成返回 I，中止返回独立设置的中止码。函数本身不会强制首点等于 I，是否发生边界跳变由表达式决定。

码值增大意味着电压降低。软件不做电压换算；512 仅表示已知的近零码，不代表精确 0 V。修改初始值后需要重新下载方案。

## 加入外部触发

1. 打开“板卡与连接 → 板卡信息”，设置“触发输入数量”，再进入“引脚配置”，在信号分组中选择触发输入。
2. 给 `trigger_in[0]`、`trigger_in[1]` 等信号填写真实 FPGA 管脚与 IO 标准。界面的“输入 1”对应 HDL 的下标 0，依此类推。参考模板输入 1/2 为 F13/F14，换板必须根据原理图确认。
3. 外部触发信号接所选输入管脚，信号地接板卡的真实 GND。匹配该 Bank 的电压和 IO 标准；不匹配时需要电平转换。`gnd0/gnd1` 是逻辑低输出，不能代替电源地接线。
4. 保存板卡，在 XDC 预览中检查，再构建新固件并烧录。UART RX/TX 管脚和 DAC 输出时序也必须完整，才能生成最终 bitstream。
5. 返回工作台：选择输出 DAC、外部触发、输入编号以及上升/下降沿。点击“下载方案”，再“布防”，等待布防确认后送入一个新的所选边沿。

**例：DAC 3 ← 输入 1 的下降沿**。选择 DAC 3、输入 1、下降沿即可；无需把第三路 DAC 固定绑定第三个输入。工作台会显示对应数据总线、时钟、触发口及当前配置管脚。“触发接线说明”子页也会实时列出映射。

输入经过同步及边沿检测。布防前已有的高/低电平不会自动启动；错误输入和错误边沿不启动。运行中再次出现所选边沿会被忽略并计数，旧固件完成后需要重新布防；支持 INFO bit3 的新固件在固定时长外部触发完成后自动重新布防。一次触发中的重复次数仍由方案决定。建议高、低电平各至少 20 ns，实际可靠脉宽与触发延迟需要在板上测量。

“软件触发”不需要额外触发线，但需 UART 连接；串口及桌面调度不适合提供确定的触发时刻。演示设备的“模拟所选触发”用于体验流程。

## 增加 DAC

1. 在板卡页面把“DAC 数量”从 2 改为需要的数量，最大 8。新增通道的数据与时钟行自动出现。DAC 数量与触发数量独立设置。
2. 每增加一颗 B 位并行 DAC，需要连接 **B 根数据线和 1 根 200 MHz 时钟线**，B 可为 10、12 或 14，另按器件要求连接供电、真实 GND 和其他控制脚。本版没有自动实现额外的 SPI 配置、片选、复位等器件专用协议。
3. 按通道筛选引脚表，填写该 DAC 的 D0～D(B−1) 和时钟管脚。不同信号不能重复占用管脚，Bank 电压要匹配，芯片封装须有足够可用 IO。
4. “DAC 时序”上方填写共用默认值，下方可以分别填写各路最小/最大输出延迟以及 DAC 的采样边沿；留空继承共用默认值。值需要根据各 DAC 手册和板上走线推导。
5. 保存或导出板卡 JSON，重新生成 XDC、构建并烧录。重新连接后，上位机从固件读取真实 DAC/触发数量；仅改页面不会改变正在运行的固件。
6. 在工作台选择新增 DAC，下载并布防。缩小再扩大数量会保留之前填写的引脚和时序；方案指向被移除的通道时会报错，不会悄悄换成其他 DAC。

| 界面通道 | 数据总线 | 时钟 |
|---|---|---|
| DAC 1 | `dac_data[9:0]` | `dac_clk[0]` |
| DAC 2 | `dac_data[19:10]` | `dac_clk[1]` |
| DAC 3 | `dac_data[29:20]` | `dac_clk[2]` |
| DAC 8 | `dac_data[79:70]` | `dac_clk[7]` |

第 n 路 Dk 对应 `dac_data[10*(n-1)+k]`，其中 n 从 1 开始，k=0～9。所有 DAC 时钟来自同一 200 MHz MMCM 输出，通过各自 ODDR 转发。实际板级时钟偏斜、DAC 接收能力和模拟输出性能需要单独验证。

已增加独立多路固件：多套播放器与存储区支持同时输出不同函数，并提供同步启动协议，见《四路DAC并行输出.md》。旧固件仍是每次一个所选 DAC 播放，其余保持中点。跨厂商时仍需要对应 PLL、DDR 输出适配器和构建工具；本版独立构建器面向 Xilinx 7 系列。

## 旧配置迁移

导入旧板卡 JSON 会自动把 `dipole_ramp` / `fm_value` 及两路旧触发、时钟名称迁移为上面的可扩展总线，物理管脚值保留。旧方案缺少触发路由字段时，默认保持“DAC 同编号输入、上升沿”的行为。

旧 XDC 的端口名称已不适用于新版顶层，需通过页面重新生成 XDC 与固件。连接旧固件时，软件只允许设备实际支持的通道及触发行为；独立路由需要新固件。新固件构建不读取参考 FPGA 源文件。
