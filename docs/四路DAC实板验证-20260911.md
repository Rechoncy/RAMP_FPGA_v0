# 四路 DAC 实板验证 · 2026-09-11

四路独立固件已生成、JTAG 下载并校验，真实 COM3 通信测试通过，随后已写入配置 Flash、逐字节回读校验，并从 Flash 重新启动成功。固件标识 USR_ACCESS 为 `09112040`。

本次四路版没有再次进行人工断电冷启动；完成的是从 Flash 重新加载验证。之前用户参与的断电验证对应旧两路固件，不能当作四路版冷启动记录。

| 四路静态码 | 分别设置 510、511、512、513，逐路回读一致，互不覆盖 |

## 使用入口

重新打开 `release/Ramp Studio.exe`，连接 COM3，然后打开“05 多路协同”。给各通道分配已保存的方案，下载勾选方案后可同时布防、同步软件触发。外部同步时在各方案中选择同一触发输入。逐路接线及操作见《四路DAC并行输出.md》。

本机 EXE 旁的板卡配置已更新为四路，并保留旧配置备份；迁移时可导入 `release/四路DAC板卡.json`。方案库未覆盖。

## 范围

同步命令在同一核心时钟发出已由 RTL 仿真检查；串口轮询仅证明实际状态与并行运行行为，不能测量物理管脚间的纳秒级偏差。本次没有示波器或逻辑分析仪读数，未实测 DAC 模拟电压、物理 200 MHz 时钟或受控外部触发边沿。DAC 型号与板级建立/保持要求未知，因此不宣称外部 DAC 接口完成时序验收。
