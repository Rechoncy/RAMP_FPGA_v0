# 电平门控版验收 · 2026-09-11

实现、测试及发布对象：独立 Python 上位机、通用 Verilog 门控播放器、Xilinx 7 系列构建脚本及 Windows x64 便携包。

## 功能验证

`python -m pytest -q`：**89 项通过**。新增门控测试覆盖：

- 10 / 12 / 14 位：完整进入、高电平无限保持、下降沿返回、自动重新布防、所选输入路由、中止码。
- 提前下降沿锁存当前码，整数线性返回；两个码值方向、非整除步长、1 拍返回、宽除数、进入末拍下降沿。
- 最小两项表以及最大 8192 项表，每项仅 1 个 5 ns 周期，进入 / 返回逐点比对，无空拍。
- 三段高斯编译、跨计算块的 800000 点离散、忽略固定保持时间、保留阶段边界、旧固件在下载前拒绝门控。
- GUI 门控选择、隐藏固定保持时间、演示上升 / 下降沿、状态与循环计数。
- 原固定时长、Debug、时间单位、位宽、串口、XDC 等回归测试通过。

RTL 使用 Icarus Verilog，仿真时钟 200 MHz；演示设备使用系统时间，两者作用不同。界面截图位于 `build/gate_gui.png`。

## Vivado 核心布局布线

Vivado 2023.1，器件 `xc7a35tfgg484-2`，50 MHz 输入，MMCM 生成 200 MHz。以下是最终 RTL 对应的实际布线报告：

| 配置 | 建立裕量 WNS | 保持裕量 WHS | BRAM Tile | 报告目录 |
|---|---:|---:|---:|---|
| 2 路 DAC / 2 输入 / 10 位 | +0.046 ns | +0.050 ns | 22.5 | `build/gate_timing10_v7/core_route_check_refined/` |
| 8 路 DAC / 8 输入 / 14 位 | +0.092 ns | +0.066 ns | 24.5 | `build/gate_timing14_v7/core_route_check/` |

10 位配置使用布线后物理优化及 Explore 路由通过；同一优化过程已加入构建脚本，时序不足时最多尝试两轮。时钟周期仍为 5 ns，未放宽约束、添加多周期例外或跳过失败路径。优化后仍失败时，构建报错且不生成 bitstream。

日志：`build/gate_refine10.log`、`build/gate_timing14_v7.log`。先前 v2…v6 的失败报告保留用于追溯，不作为最终验收结果。

**这不是整板验收或硬件实测。** UART RX/TX 和 DAC 外部时序尚需用户按实际板卡填写，本次未生成最终 bitstream、未烧录、未测量模拟电压或触发延迟。12 位通过功能仿真，未单独做本轮布局布线；其他器件及配置应通过硬件页面重新实现并检查。

## 便携发布

最终输出 `release/Ramp Studio.exe` 和 `release/Ramp-Studio-Windows-x64.zip`。打包验证执行两次迁移路径启动（含中文、空格），清理 Python / Qt 相关环境，覆盖离线演示、门控、Debug、混合时间单位和重新加载方案。

另从打包 EXE 调用内置构建进程及本机真实 Vivado 生成工程，确认持久化 RTL / Tcl 与工作区最终版本逐字节一致，工程不引用临时解包目录或原参考 FPGA 工程。详细记录见 `build/validation_executable.json`；发布校验值见 `release/SHA256.txt`。

发布时保留原 EXE 备份，不改写现有 `user_data`。操作说明见 [电平门控](电平门控.md)。
