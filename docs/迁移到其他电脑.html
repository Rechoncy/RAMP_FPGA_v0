Ramp Studio 迁移说明（具体文件夹清单）

适用系统：Windows 10/11，64 位（x64）。以下路径中的 D:\RampStudio 是新电脑上的示例位置，可以换成其他可写目录。

一、最省心的方法：复制整个 release 文件夹

本机需要复制的文件夹只有这一个：

E:\Github_Project\RAMP_FPGA_v0\release

这个 release 文件夹内已经包含程序、现有实验数据、手册、示例和当前固件资料。整文件夹复制即可，不用逐个挑选文件。

操作步骤：

  1. 正常关闭 Ramp Studio，等待窗口退出；软件会自动保存设置和草稿。若希望本次编辑成为供 DAC 选择的版本，先点击对应“保存方案”。出现保存失败提示时先处理，再继续复制。
  2. 在文件资源管理器中打开 E:\Github_Project\RAMP_FPGA_v0，复制名为 release 的整个文件夹。
  3. 在新电脑新建 D:\RampStudio 文件夹，将刚才的 release 文件夹粘贴进去。
  4. 打开新电脑的 D:\RampStudio\release 文件夹。
  5. 双击 D:\RampStudio\release\Ramp Studio.exe 启动。

程序文件名是 Ramp Studio.exe，中间有一个空格；实验数据文件夹名是 user_data，中间是下划线。

二、复制完成后应当是什么样子

D:\RampStudio\

user_data 内的文件会随实际使用变化。例如使用触发步进后可能出现 scan_draft.json，确认下载后可能出现 loaded_waveforms.json。不需要手动新建这些文件，只需完整复制现有 user_data，包括里面的全部文件和子文件夹。

desktop_session.json 包含尚未完成的板卡 / Flash 输入、波形 / 序列 / 扫描草稿、时间单位、DAC 分配、Debug 待提交原码、首选串口、连接波特率和上次页面。正常退出后该文件随数据目录迁移；只复制 board.json 或单个方案 JSON 无法带走完整编辑进度。有效板卡设置（含UART 上电默认波特率）另存于 board.json，无效或不完整输入仅作为草稿保留。

四、使用压缩包迁移的方法

如果希望传输的文件更小，可以使用以下两项替代整个 release 文件夹：

本机的准确来源路径 操作
E:\Github_Project\RAMP_FPGA_v0\release\Ramp-Studio-Windows-x64.zip 复制到新电脑，解压到 D:\RampStudio\release
E:\Github_Project\RAMP_FPGA_v0\release\user_data 整个文件夹复制到上述解压目录，与 EXE 放在同一级

压缩包解压后包含 EXE、说明、文档、许可和示例，不包含本机实验数据，也不包含独立的固件发布包。只复制 ZIP 会启动一套新数据。若还要带走已生成的固件，另外复制：

E:\Github_Project\RAMP_FPGA_v0\release\FPGA-XC7A35T-TriggerScan.zip

解压后的启动路径仍为：

D:\RampStudio\release\Ramp Studio.exe

使用“全局保存 / 全局导入”迁移方案和设置

若只需要方案库、板卡设置和当前编辑进度，可以用一个工作区包代替手动复制 user_data：

  1. 在旧电脑的软件左侧 FPGA 信息下方点击“全局保存”，例如保存为 E:\RampBackup\实验A.ramp-workspace。软件先保存当前会话，包括未保存草稿。
  2. 将以下两个文件复制到新电脑：E:\Github_Project\RAMP_FPGA_v0\release\Ramp-Studio-Windows-x64.zip 和刚导出的 实验A.ramp-workspace。
  3. 把便携 ZIP 解压到 D:\RampStudio\release，双击其中的 Ramp Studio.exe。工作区包可以放在 D:\RampStudio\备份\实验A.ramp-workspace，无需放入或解压到 user_data。
  4. 保持未连接，在左侧点击“全局导入”，选择该包，核对摘要后确认。导入会替换接收端本地方案及设置，不合并两套方案库。
  5. 软件先将接收端工作区备份到 D:\RampStudio\release\user_data\archive\workspaces，再导入并重新打开工作区，保持未连接。实际数据位置变更时，以“打开数据目录”为准。
  6. 核对恢复内容，重新选择新电脑的 COM 端口、Vivado 及外部 BIT / Flash 备份路径，再连接板卡。

工作区包包含所有保存的波形 / 序列 / 扫描方案、未保存草稿、板卡 / 引脚 / 时钟 / UART / Flash 设置、上电方案快照、DAC 分配、Debug 待提交值与界面会话。草稿保持草稿身份；想用于 DAC 输出时仍需保存方案并准备。导入不会自动连接、下载、布防、应用静态输出或修改硬件 Flash。

该包不包括 EXE、Vivado、生成固件、Flash 内容、日志、Flash 作业、构建缓存、历史 archive、资源报告及报告选择，也不包含 loaded_waveforms.json 设备确认缓存。导入保留接收端这些已有文件；本机报告会按新板卡配置重新核对，导入方案不会被视为设备已下载确认。引用外部文件只记录路径文本，不带文件本身。要一起保留这些历史记录，仍采用整份 release 或 user_data 复制法，并另行复制目录外的固件与备份。需要撤销工作区替换时，在“全局导入”中选择 user_data\archive\workspaces 对应的自动备份包。

五、不要选错两个 user_data 文件夹

本工作区有两个名称相同、用途不同的数据文件夹：

本机完整路径 用途 本次 EXE 迁移
E:\Github_Project\RAMP_FPGA_v0\release\user_data 双击 EXE 或现有快捷方式启动时使用 复制这一份
E:\Github_Project\RAMP_FPGA_v0\user_data Python 源码启动时使用 不要拿它覆盖上面那一份

如果曾主动通过环境变量 RAMP_STUDIO_DATA_DIR 改过位置，或程序因目录不可写而改用 %LOCALAPPDATA%\RampStudio\user_data，先在软件里点击“打开数据目录”，复制实际打开的文件夹。新电脑已有其他实验数据时，先选择一个新的接收文件夹，避免覆盖。

六、新电脑上的首次启动

  1. 双击 D:\RampStudio\release\Ramp Studio.exe，确认原有方案、DAC 分配和上次编辑草稿能够显示。软件保持未连接；恢复首选串口或 Debug 输入不会自动连接、下载、布防或应用静态输出。
  2. 不接硬件时选择“演示设备 · 无需硬件”。上位机无需另外安装 Python、Qt 或 NumPy。
  3. 连接实板时安装对应 USB-UART 驱动，进入“板卡与连接”重新选择新电脑的 COM 端口，并选择所需“波特率”（旧固定速率固件须匹配原值）。该选择在断开后可改，正常退出会保存；首选值随 user_data 迁移，但不代表新电脑的 USB-UART 已通过该速率验证。
  4. 只有生成固件、JTAG 或 Flash 操作才需要安装 Vivado、器件支持及 JTAG 驱动。在“板卡信息”中选择新电脑的 vivado.bat。
  5. 如果要使用已有 BIT、Flash 备份或旧工程，重新选择它们在新电脑上的实际路径。旧 Vivado 工程建议由新电脑上的 EXE 重新生成。
  6. 需要桌面启动图标时，为新位置的 Ramp Studio.exe 重新创建快捷方式。不要直接使用本机工程根目录的 Ramp Studio.lnk，它可能仍指向旧电脑的 E 盘。

换电脑本身不需要重新烧写 FPGA。软件与板上固件的功能仍需匹配：新增触发步进需要支持它的固件。普通方案下载写入 FPGA 易失配置，板卡掉电后能否恢复，取决于是否已经将自己的方案纳入 Flash 上电镜像。

默认串口速率为 115200，最高预设为 1,000,000 baud（1M）。新版 FPGA 固件连接时自动识别全部九档速率，切换只需断开、选择、重连；旧固定波特率固件先升级一次。仅迁移软件或配置不会升级板上固件。如需掉电继续使用新功能，应固化包含自动识别逻辑的新固件；每次换速率不必再改 Flash。详见 UART 自动波特率。

目录清理和历史归档位置见 目录与归档说明。

七、高速 USB / UART 双接口版本的迁移

复制清单保持不变：复制整个 E:\Github_Project\RAMP_FPGA_v0\release，或在新电脑解压便携 ZIP 并迁移完整 release\user_data / 导入全局工作区包。无需额外复制 USB 接口工程；生成器及 RTL 已随 EXE 打包。

USB 设置和引脚随数据迁移

  • 有效板卡配置保存在 release\user_data\board.json，包含 USB 启用状态、IO 标准、时序、完整接口引脚以及UART 上电默认波特率。
  • 未完成的编辑保存在 release\user_data\desktop_session.json；正常退出后复制整个 user_data 可一并带走。
  • 全局保存的 .ramp-workspace 同样包含板卡及草稿内容。导入后保持未连接，不自动构建、下载、布防或烧写。
  • “板卡信息 → 高速 USB 通信”配置可选 USB 接口；引脚在独立“引脚配置”页修改，保存后重新生成 XDC 和 Vivado 工程。

新电脑仅使用已烧录固件时无需安装 Vivado。需要生成或烧写固件时，安装 Vivado、目标器件支持和 JTAG 驱动，并选择新电脑的 vivado.bat。不同板卡必须重新核对引脚和电气约束，不应直接套用达芬奇模板。

驱动与物理插口

要使用的功能 新电脑所需驱动 / 接口
UART 串口 USB-UART 驱动，例如 CH340；接开发板 USB UART，选择 COM 端口及波特率，旧固件须匹配原值
FT232H 高速下载 Windows x64 FTDI D2XX 驱动；接独立 USB SLAVE 插口，在软件选择 USB FIFO · 序列号
FPGA / Flash 烧写 Vivado 与 JTAG 驱动；接 JTAG 接口

FTDI D2XX 是系统驱动，不由 user_data 或全局工作区包携带。复制 EXE 不会自动安装它；CH340 驱动也不能替代。缺少 FTDI 驱动不影响串口与演示模式。FT232H 应已配置为 245 FIFO 模式，软件不会自动改写 EEPROM 或替换系统驱动。

启用 USB 的同一份固件支持 USB FIFO 和 UART，软件选择其中一个连接。切换时先断开当前连接，再选择另一接口；不要由两个程序同时控制同一板卡。切换接口本身不要求重新烧录，但首次从旧 UART 固件升级到 USB 双接口功能，需要显式生成并烧录新固件。迁移配置或只更新 EXE 不会改变板上逻辑。

波形存储和掉电行为

本版使用 BRAM，四路配置每路每 bank 2048 段，逐码保持最短 5 ns，插值段最短 160 ns；不存在此前 DDR3 方案的 1.28 μs 下限。DDR3 路径已撤销，不再提供 MIG 设置。

电脑数据包保存方案与设置，不包含 FPGA 当前 RAM 内容和运行进度。普通下载的波形在掉电后丢失；要上电独立使用，应把所需方案纳入上电快照，构建对应比特流并显式固化 Flash。普通 USB 下载和 UART 下载均不自动修改 Flash。

详细配置入口、XDC 换板步骤及验证范围见 高速 USB 与串口 与《软件详细使用手册》第 21 节。

2026-09-17 实板验证版本

需要自动波特率和 3PD5651E 的 125 MSPS 固件时，另外复制 release\FPGA-XC7A35T-AutoBaud-20260917-R2.zip。新 BIT 位于其中的 125MSPS\ramp_studio.bit，已完成仿真、实现和时序检查，并在当前 CH340 上通过九档切换及四路播放实板数字验证。标识 09171830 已临时 JTAG 加载，Flash 未写，掉电会恢复 Flash 原版本。本版先升级一次，以后切换波特率只需断开、选择、重连。详细记录见 UART 实板验证。下面保留早期 USB 数字联调记录，其 200 MHz 固件不用于当前 125 MSPS DAC。

已验证的四路 10 位双接口固件为 09171701，放在 release\FPGA-XC7A35T-USB-UART-20260917\，也提供同名 ZIP。仅复制软件便携 ZIP 时，如需在新电脑重新烧写，请另外复制这个固件 ZIP；软件便携包不包含 BIT。

本机当前仅通过 JTAG 临时配置了该固件，未改 Flash。板卡断电后会回到原 Flash 版本 09112040，需重新临时下载新 BIT 才能使用本次 USB 功能。现有 release\user_data 已保存 USB 引脚、首选数据设备以及上升沿 / −0.5～1.0 ns 的诊断时序假设；原实验方案与 Flash 上电快照保留。该 BIT 自身不包含这些实验快照。换板或换 DAC 时需核对真实时序参数，不能将诊断值视为永久通用约束。详见 USB 实板数字验证。
