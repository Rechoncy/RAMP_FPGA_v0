# 验收记录（DAC 200 MHz 更新）

本文保留“DAC 时钟改为 200 MHz、旧分段执行器最短 80 ns”的历史快照。后续单幅度/自定义函数播放器已支持 5 ns 逐点更新，最新功能及限制见 [函数波形与 DAC 选择](函数波形与DAC选择.md)，最新验证见 [函数播放器验收](函数播放器验收.md)。下文旧时序数值不用于新增播放器。

日期：2026-09-10。当前板卡目标 `xc7a35tfgg484-2`，参考时钟 50 MHz，核心与两路 DAC 接口共享 200 MHz 时钟。两路数据寄存器及 ODDR 转发时钟均使用同一 MMCM 输出。

DAC 时钟周期为 5 ns；波形执行器最短更新间隔仍为 80 ns，间隔设置步进为 5 ns。连接旧固件时，上位机保留按设备能力处理 50 MHz DAC / 20 ns 间隔步进的兼容逻辑。

## 尚未完成的硬件验收

目前没有连接开发板，也没有收到 UART 实际管脚和 DAC 数据手册。默认板卡的 UART 管脚和 DAC 外部延迟仍是待设置项，已放入“硬件与约束”页面。

上述时序通过仅指**当前约束下的内部路径和相关时钟传输**。报告仍列出未提供的 DAC 输出时序；其 “All user specified timing constraints are met” 不能解释为所有物理 IO 已验收。更改 UART 管脚、DAC 延迟或目标器件后必须重新实现，现有裕量不能保证迁移后的结果。

当前 DRC 仍有 UART 的 NSTD-1、UCIO-1，原因是 uart_rx/uart_tx 管脚及 IO 标准尚待实际板卡设置。配置电压属性缺失提示已消除。没有降低 DRC 严重等级来生成 bitstream。XDC 页面包含 CFGBVS / CONFIG_VOLTAGE 设置，默认值沿用原工程的 VCCO / 3.3 V。最终 bitstream 流程要求所有引脚及 DAC 延迟完整，并由 Vivado 的时序与 DRC 检查决定是否能生成。

**没有生成或烧录最终 bitstream，没有进行 DAC 模拟电压、触发延迟、脉宽容限、失锁恢复或 Flash 上电启动的板上测量。**
