# GitHub 源码仓库使用说明

仓库保存 Python 上位机、独立 FPGA RTL、Vivado 构建脚本、板卡模板、示例、测试和文档。`Assistant_FPGA/` 保留最初参考工程的源码与工程配置，新软件和新固件构建不依赖该工程。

Git 不跟踪本机 `.venv/`、`build/`、`release/`、`archive/`、用户实验数据 `user_data/`、Vivado 缓存、快捷方式和生成的 BIT / EXE。手册中的这些路径指本地构建或此前交付资料，下载 GitHub 源码后不会自动存在。请单独保留自己的实验数据；源码仓库不能替代实验数据备份。

## 从源码启动

当前开发环境为 Windows x64、Python 3.12。在仓库根目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m host.app
```

演示模式无需 FPGA、Vivado 或 USB 驱动。实际串口连接需要对应 USB-UART 驱动；FT232H USB FIFO 使用 Windows x64 D2XX 驱动。在板卡页面指定本机的 Vivado 安装路径和实际接线，不要直接套用其他板卡的 XDC。

## 构建与验证

- 在上位机“板卡与连接”设置型号、时钟、位数、通道、引脚与 DAC 时序，再生成独立 Vivado 工程。当前已验证工具链为 Vivado 2023.1 / Xilinx 7 系列。
- Windows 便携程序：在根目录执行 `Build-Executable.ps1`，输出到本机 `release/`。
- 离线 HTML 手册：安装 `requirements-docs.txt` 后执行 `scripts/render_manuals.py`。
- 软件测试需另安装 pytest；RTL 测试还需要 Icarus Verilog 的 `iverilog`、`vvp` 位于 PATH。可运行 `python -m pytest tests/test_uart_host.py tests/test_usb_transport.py -q`，完整测试使用 `scripts/run_regression.py`，先查看其命令行参数。
- `scripts/verify_*device.py` 是真实硬件诊断脚本。先阅读脚本说明；数字输出测试可能覆盖 FPGA 中的暂存波形，不应在正在进行的实验中运行。

2026-09-17 验证结果见 [UART R2 实板验证](UART实板验证_2026-09-17.md) 和 [USB FIFO R2 实板验证](USB_FIFO_R2实板验证_2026-09-17.md)。这些是当时指定板卡和构建的实测记录，不代表从源码重新构建的任意板卡均已通过验证。对 FPGA 的临时下载及 Flash 固化需要另外执行，不会随 Git clone 或程序启动自动发生。
