# Flash 固化验证 · 2026-09-11

当前结论：Flash 写入、Vivado 校验、独立逐字节回读、从 Flash 重新启动，以及用户确认断电再上电后的冷启动验证，全部通过。

## 实板与镜像

- FPGA：xc7a35t，工程器件 xc7a35tfgg484-2。
- JTAG：Digilent 210512180081；串口：COM3，115200 8N1。
- Flash 实读 JEDEC：20 BA 18；Vivado 匹配配置 mt25ql128-spi-x1_x2_x4（兼容名称 n25q128-3.3v-spi-x1_x2_x4），容量 128 Mbit / 16 MiB。此处是兼容编程配置，不代表已读到完整封装订货型号。
- 启动模式引脚：M[2:0] = 001。
- 固化镜像：SPIx1，配置时钟设置 16 MHz，压缩，起始地址 0x00000000，镜像数据长度 582744 字节。配置时钟仅用于启动加载；应用核心与 DAC 仍为 200 MHz。
- 本次固化固件标识 USR_ACCESS：09111930；之前 SRAM 联调固件为 09111720。
- 使用已有通过内部时序的 routed.dcp 生成，仅修改启动相关属性，未修改 RTL 或管脚。DAC 外部建立/保持时序仍未知，保持数字联调版验收边界。

## 已完成的验证

1. 只读识别 Flash，写入前完整备份 16777216 字节。
2. 按镜像地址范围擦除、空白检查、编程、Vivado Verify，全部成功。
3. 独立回读 Flash 地址 0 开始的 582744 字节，与生成的 BIN 逐字节一致。
4. 调用 boot_hw_device 让 FPGA 从 Flash 重新加载，未通过 JTAG 下载应用比特流；USR_ACCESS = 09111930，DONE = 1，CRC_ERROR = 0。
5. 实际 COM3 INFO / STATUS 正常：核心 200 MHz、DAC 分频 1、10 位、2 路 DAC、2 路触发、支持门控。启动后空闲、码值 512、PLL 锁定，未下载实验方案。

## 已完成：真实冷启动

用户按完全断电、等待约 5 秒再上电的要求操作并回复“已重启”。2026-09-11 19:15:33 开始验证，期间没有重新编程 FPGA 或 Flash。

只读检查脚本：`scripts/vivado/verify_flash_boot.tcl`。检查得到 USR_ACCESS = 09111930、DONE = 1、INIT_B = 1、CRC_ERROR = 0、IDCODE_ERROR = 0。串口 COM3 正常，首次状态为未下载方案、空闲、码值 512、PLL 锁定。

随后运行 `scripts/verify_connected_device.py`，通过两路静态码 511/513/512、DAC 1 Ramp 与 DAC 2 三段高斯 512 → 508 → 512（各重复两次），以及两路门控输入的配置、布防和取消测试。门控测试没有施加受控外部边沿，不属于外部边沿实测。

结束后两路恢复中点码 512、未布防；串口和 JTAG 会话均释放。用户可直接在上位机连接 COM3，下载自己的方案并布防，无需再次烧录。

## 固化范围

固化的是 FPGA 固件。下载到运行 RAM 的实验波形、静态 Debug 值与布防状态不持久化；上电后回到默认中点码 512、未布防。使用时从上位机重新下载所需方案并布防。
