# XC7A35T 数字联调固件 · 已实板下载并校验

目标：xc7a35tfgg484-2；参考时钟 50 MHz；核心和两路 10 位 DAC 转发时钟 200 MHz。
UART RX=U5，TX=T6，其余管脚见 board.xdc。文件只适用于这一管脚映射与器件配置。

2026-09-11 已通过 JTAG 下载至连接的 XC7A35T，并用对应 .msk 执行 verify_hw_devices，配置回读比对通过。
DONE=1，INIT_B=1，CRC_ERROR=0，IDCODE_ERROR=0，镜像 USR_ACCESS=09111720。
本次布局布线内部建立裕量 +0.083 ns、保持裕量 +0.062 ns，DRC 违规 0 项。

这是 FPGA 易失配置，断电后本次下载内容不保留；没有改写板载启动 Flash。
重新下载时，在 Vivado Hardware Manager 连接目标 XC7A35T，Program Device 选择 ramp_studio_digital_test.bit。
如需再次配置比对，可关联同名 .msk 后执行 verify_hw_devices。

DAC 型号、建立/保持时间、采样边沿未知，所以 XDC 只补齐管脚和 FPGA 内部时钟/CDC约束，DAC 外部时序仍明确保留 TODO。
此文件用于数字联调，不代表已证明 DAC 在 200 MHz 下可靠接收数据；未测量时钟引脚、DAC 数字引脚或模拟波形。
不会以填 0 ns、放宽时钟或降低 DRC 等级来声称完成外部时序验收。

本次检测不到 UART 串口，尚未进行真实上位机 INFO/STATUS 通信和触发波形验证。
JTAG 用于配置 FPGA，UART 用于上位机下发参数。连接开发板的 USB-UART、确认驱动出现 COM 端口后，
在 Ramp Studio 刷新并选择真实串口，连接后先用 Debug 输出静态码，再下载波形、布防并接入外部触发。
未下载方案时，固件设计默认两路输出码 512；该描述不是实测输出结果。

详细机器可读记录见 validation.json，文件校验值见 SHA256.txt。
