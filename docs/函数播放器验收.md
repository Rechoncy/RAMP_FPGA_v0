# 函数播放器验收

> 本文为前一版历史记录。当前版本见 [扩展版验收](扩展版验收.md)。

日期：2026-09-10。目标为 `xc7a35tfgg484-2`，Vivado 2023.1；50 MHz 参考输入、200 MHz 核心和两路 DAC 时钟。

## 功能验证

当前自动测试共 36 项。覆盖范围：

- Python 原码函数的逐点采样、半整数四舍五入、0/512/1023 边界、正/负方向 Ramp。
- 拒绝非数学代码、非法定义域、NaN/无穷、码值越界、容量超限；跨计算分块的重复码正确合并。
- FPGA 每拍输出比较：1/2/4/8192 个单拍码段、71 个混合时长码段，三次循环，中止后重新布防。
- 协议能力发现、不完整下载禁止提交、双 bank 切换、布防期间禁止下载；DAC 1/2 输出路由和所选外部触发。
- Python 生成的 11 帧 UART 比特流进入实际串口接收与控制模块，检查应答 CRC，并逐拍确认 DAC 2 的 12 个采样周期以及 DAC 1 保持 512。
- 旧分段协议的 18 帧 UART 回归、原插值执行器逐点测试，以及配置除法最大商/大分母边界。
- Qt 界面：Ramp 编辑、下载、修改后禁止布防、外部模拟触发；切换函数与 DAC 2，完整离散检查、下载、播放完成、回到 512。

界面截图：`build/ramp_studio_workbench.png`、`build/ramp_studio_function.png`、`build/ramp_studio_hardware.png`。图形检查已确认无控件遮挡，函数预览标注为抽样显示，完整离散检查在后台执行。

## FPGA 时序验证

最终内部检查工程：`build/studio_functions200_v3/ramp_studio.xpr`。

| 检查 | 结果 |
|---|---|
| 布局布线建立时序 | WNS **+0.202 ns**，TNS 0，10076 个端点无失败 |
| 布局布线保持时序 | WHS **+0.060 ns**，THS 0，10076 个端点无失败 |
| 两路 DAC 时钟 | 均为 5.000 ns / 200.000 MHz |
| Vivado XSim | 实际生成的 Clocking Wizard + UNISIM MMCM/ODDR 模型通过；20 个连续周期为 5 ns，高电平 2.5 ns，两路同相，数据同核心边沿寄存 |
| CDC | 3 个异步输入同步路径全部 Safe，Unsafe=0，Unknown=0 |
| 资源 | 1725 LUT（8.29%）、3148 FF（7.57%）、22.5 BRAM Tile（45%）、0 DSP、1 MMCM |
| DRC 剩余项 | uart_rx/uart_tx 尚未配置，保留 NSTD-1 / UCIO-1；未降低检查级别 |

配置除法已拆分流水，循环边界在运行前计算；保持真实 5 ns 时钟约束。上述通过范围是已约束的内部路径，DAC 板级输出延迟尚未填写，不构成完整硬件时序签核。

报告保存在工程的 `core_route_check/`：`timing.rpt`、`cdc.rpt`、`drc.rpt`、`utilization.rpt` 和 `routed.dcp`。`source_inputs.txt` 记录独立工程输入，`build/validation_functions200_manifest.json` 记录验证版本与源码哈希。

## 独立性与未完成项

新生成工程只包含 `rtl/common/*.v`、`rtl/platform/xilinx_7series/*.v`、页面生成的 XDC 和新建 Clocking Wizard。没有引用参考 `Assistant_FPGA/` 的代码、IP 或检查点。

尚未连接实际开发板；UART 引脚与 DAC 输出延迟仍待用户在子页面按硬件资料填写，因此未生成最终 bitstream、未烧录，也未测量模拟电压。内部时序和仿真通过不代表全部板级 IO 验收完成。

当前播放器上限为每 bank 8192 个连续码段，主机单次完整采样最多 1 秒 / 2 亿点，超限明确拒绝，不降采样。其他厂商 FPGA 仍需对应平台时钟与 IO 适配器。
