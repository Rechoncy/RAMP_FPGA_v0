# 三段自定义函数

自定义函数默认由三个阶段组成：**初始码 I → 目标码 A → 保持 A → 返回 I**。

1. 在“方案设计与保存”选择“自定义函数”。
2. 设置初始 / 结束码、目标幅度码、中止码，以及进入、保持、返回三个时长。
3. 点击“高斯”“余弦平滑”或“线性”应用模板，也可分别编辑进入段与返回段表达式。
4. 查看带阶段分界的预览，执行“完整离散检查”，保存后进入 DAC 页面选择该方案，再下载并布防。

例如 10 位 DAC：初始码 512、目标码 112、进入 1 ms、保持 2 ms、返回 1 ms。点击高斯后，前半高斯从 512 平滑接到 112，随后保持 112，再沿后半高斯返回 512。电压极性仍由实际 DAC 决定，软件只处理原码。

## 公式变量和端点

- `I`：初始码；`A`：目标码，直接使用当前 10/12/14 位 DAC 的整数原码。
- `t`：**本阶段**的时间，从 0 重新开始，单位秒。
- `T`：本阶段按 5 ns 量化后的时长，单位秒。
- 进入段必须满足 `f(0)=I`、`f(T)=A`；返回段必须满足 `f(0)=A`、`f(T)=I`。
- 中间保持段自动输出 A，无需填写函数。公式仍支持 sin/cos/exp/where/clip 等；乘方使用 `**`。

高斯模板在有限区间截取 3σ 半高斯，并归一化端点，避免截断尾部与初始码衔接时出现固定偏差。令 `u=t/T`：

```text
进入：I + (A-I)*(exp(-4.5*(1-u)**2)-exp(-4.5))/(1-exp(-4.5))
保持：A
返回：I + (A-I)*(exp(-4.5*u**2)-exp(-4.5))/(1-exp(-4.5))
```

界面公式使用 `t/T` 代替 u。分别设置进入和返回时长可以得到不对称的脉冲；目标码既可高于也可低于初始码。

## 采样与兼容

每段时长分别四舍五入到整数个 5 ns 周期，然后在该段 `t=0,5 ns,…,T−5 ns` 采样。边界由下一段或结束后的初始码接续；没有额外插入保持采样点。每个函数值四舍五入为整数 DAC 原码，连续相同码值无损压缩。0 时长代表跳过该段；非零时长量化后不足一个周期会报错。

总采样时长上限 1 秒，编译器压缩上限为 8192 个连续码段；下载还须满足设备回报的每路容量，当前四路固件为 2048 段/路，超限明确报错；不会改变 200 MHz 采样率。阶段端点、定义域和原码范围仍须通过检查。

旧 JSON 中没有 `function_layout` 的整段函数保持原来的输出语义，在界面显示“旧版整段函数”。点击任一新模板可切换到三段结构；请确认目标码、三个时长，再保存和重新下载。原有方案不会自动改写。

本功能通过上位机生成现有 200 MHz 播放器支持的码段序列，未修改 FPGA 协议、DAC 位宽或 RTL，现有支持函数播放的固件无需为此重新烧录。
