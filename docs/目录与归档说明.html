2026-09-16 USB / UART 版本收尾清理

本轮取消 DDR3 路径后，清理范围包括不再使用的 DDR / MIG 临时配置与生成缓存、历史便携验证目录中的重复 EXE、旧 PyInstaller 中间文件，以及已确认可再生成的测试缓存。源码中的 USB 并行 FIFO 和 UART 双接口、BRAM 播放器及正式验证报告继续保留。

本次清理按明确清单逐项执行，不整体清空 build 或 release。文件删除前复核 SHA256；重复 EXE 还需核对保留文件或正式回退 ZIP 内条目的 SHA256。目录复核路径、文件列表、修改时间、大小和内容指纹，重建后不再匹配的缓存跳过。所有删除目标限定在当前项目内，拒绝重解析点和保护路径。本轮脚本直接删除验证通过的临时产物，不沿用 9 月 13 日的回收站方式。

本轮记录 用途
build/usb_uart_final_20260916/cleanup_inventory.json 初始占用清单
build/usb_uart_final_20260916/cleanup_plan.json 审阅后的明确目标、保留副本和保护路径
build/usb_uart_final_20260916/cleanup_snapshot.json 目录文件与修改时间指纹
build/usb_uart_final_20260916/cleanup_dryrun.json 删除前预演；不表示已经删除
build/usb_uart_final_20260916/cleanup_result.json 正式执行结果，记录删除、跳过、失败和实际确认释放字节数

本轮清理已完成：主清单删除 92 项，补充清单删除 60 项，共移除 3,127,257,311 字节的临时文件和重复副本。扣除新保留的诊断归档，净释放约 3.13 GB（2.91 GiB）。4 个变化过的缓存最初被跳过，随后重新核对并纳入补充清理。补充脚本处理空目录时中断过一次，修复后从已记录的删除状态完成剩余项目，完整记录保留在 cleanup_supplement_partial_items.json 与 cleanup_supplement_result.json。

清理前后校验 463 个受保护文件，全部保持该次清理前的 SHA256。更早的会话保存曾更新 release/user_data/desktop_session.json，未将其回滚到旧版本。汇总见 清理记录；本地完整证据为 build/usb_uart_final_20260916/cleanup_final_summary.json。失败候选的诊断日志、报告、约束与生成源码保存在同目录两份 failed_candidate*_cache_evidence.zip，最终成功布局工程与 routed.dcp 直接保留。

以下内容明确保护：

  • Assistant_FPGA/：用户最初提供的完整参考工程。
  • user_data/ 与 release/user_data/：两种启动方式的实际方案、草稿、配置和日志，均不清理或合并。
  • build/usb_uart_final_20260916/：本轮最终综合、时序、回归测试、发布与清理报告；不纳入整体目录删除。
  • build/linear14_validation/、build/connected_board_20260916_170449/ 及必要的历史资源、时序和数字验证记录。
  • archive/软件回退/ 与 archive/历史固件/：正式回退软件及历史固件，特别保留 archive/软件回退/Ramp-Studio-Before-USB-UART-20260916.zip。
  • 当前 release/Ramp Studio.exe、便携 ZIP、源码、文档、示例与本机 .venv/ 开发环境。

本轮只整理电脑项目文件，不执行板卡烧写、Flash 操作或 DAC 输出。
